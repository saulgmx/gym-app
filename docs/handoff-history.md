# Historia del proyecto Gym app

Archivo de consulta: lo que ya está hecho, fase por fase, movido desde `handoff.md` el 20-nov-2026 para que el handoff solo lleve el estado actual. No hace falta leerlo para retomar el trabajo. La fuente de verdad de cada fase son su spec, su plan y sus tareas (`docs/specs/NNN-*/`) y los contratos (`docs/modules/*.md`), que mandan sobre este resumen.

Las secciones están copiadas tal como estaban en `handoff.md` al moverlas.
